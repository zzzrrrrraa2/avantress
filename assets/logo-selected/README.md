# Selected Aventress logo system

- `aventress-primary.png` — wordmark with the custom capital `A` from concept
  14 and a conventional, independent lowercase `v`, without supporting text.
  Intended for the website header and compact placements.
- `aventress-with-descriptor.png` — matching wordmark with
  `ADMINISTRATION · BACK OFFICE` beneath it. Intended for documents, social
  profiles, presentations, and placements where the service needs explaining.

Both files preserve the custom capital `A` treatment from concept 14 while
using a normal lowercase `v`.

## Image-generation prompt

The primary version was created by preserving concept 14's capital `A` and
restoring a conventional lowercase `v`. The descriptor version preserves that
corrected wordmark and adds the exact text
`ADMINISTRATION · BACK OFFICE` once in small, tracked, deep-green monospaced
type beneath it.

These PNGs are selection masters. Before final production use, the chosen
lettering should be redrawn as SVG so it stays sharp at every size and can be
exported with transparent, cream, and reversed backgrounds.
